K2K Packet Desktop — Quick Start

Connect

Enter your Direwolf TNC's IP and Port in the top bar, then click Connect. The default port is 8000 for AGW or 8001 for KISS. Set your callsign in the Settings panel (⚙ gear icon). The connection status indicator turns green when connected.

Connected Mode (C1–C4 Tabs)

The four tabs C1 through C4 let you run up to four separate connected-mode sessions simultaneously. Click a tab to select it.

:c CALLSIGN

Type :c followed by a callsign and press Enter to initiate a connected-mode session. Optionally fill the Via field with digipeaters (space-separated). Example: :c KD7ABC or :c KD7ABC-3 with Via: DIGI1 DIGI2

:d

Type :d and press Enter to disconnect the current tab's session.

Once connected, type a message and press Enter to send it. Use Shift+Enter for multi-line messages. Arrow keys navigate your send history.

Unproto Mode (UI Frames)

The right panel displays all received and sent unproto (UI) frames. You can transmit unproto frames using the input fields at the bottom:

  • To — destination callsign (required)
  • Via — digipeater path (optional, space-separated)
  • Message — the text to send

Click Simple Unproto to toggle simplified header display. Click Deduplicate Packets to filter duplicate UI frames from different digipeaters.

Beacon

Set up an automatic beacon in Settings (⚙). Enable the beacon, set your beacon text, destination (default BEACON), optional Via path, and interval in minutes. The beacon transmits automatically while connected.

Tips

- Auto-connect — enable in Settings to connect automatically on app startup.
- Clear buttons clear the message log or unproto display.
- Retry indicator — shows T1 retry count and timeout during connected-mode sends.
- Raw KISS — enable in Settings to see raw hex KISS frames instead of decoded messages.
- Settings are saved to disk and persist across restarts.
